# Detallitos 🎁

Página web de **Detallitos**, tienda de regalos, librería y sublimación ubicada en Tilarán, Guanacaste, Costa Rica.

> "Un regalo, una sonrisa"

## 📌 Sobre el proyecto

Este es mi primer proyecto de portafolio personal. La idea es seguir desarrollándolo y mejorándolo poco a poco hasta convertirlo en la página real del negocio.

## 🗂️ Estructura del proyecto

```
detallitos-web/
├── index.html      # Estructura de la página
├── css/
│   └── style.css   # Estilos
├── js/
│   └── script.js   # Interactividad (confeti animado, etc.)
├── img/             # Imágenes (logo, productos, fotos)
└── README.md
```

## 🚀 Cómo verla localmente

Abrir `index.html` directamente en el navegador.

## 🛠️ Tecnologías

- HTML5
- CSS3 (variables CSS, animaciones, diseño responsive)
- JavaScript vanilla
